## 🚀 Projeto em destaque

### Tech Logística — Sistema de Gestão de Entregas & Event-Driven Logistics
`TypeScript` `Node.js` `React` `Redis` `Kafka` `PostgreSQL` `TailwindCSS`

🔗 [github.com/mahvalenterj/app-logistics-delivery-ddd](https://github.com/mahvalenterj/app-logistics-delivery-ddd)

Ecossistema completo para gestão de operações logísticas e rastreamento de entregas:

- **Arquitetura Event-Driven & Máquina de Estados** — Máquina de Estados Finita (FSM) orquestrando o ciclo de vida dos pedidos (`Created` → `Accepted` → `OnTheWay` → `Completed`).
- **Mensageria & Alta Disponibilidade** — barramento de eventos assíncronos integrando tópicos no Apache Kafka (`order-created`, `delivery-assigned`, `delivery-status-updated`) e cache em tempo real com Redis para cotações de frete e consultas de CEP.
- **Full-stack & Métricas** — API RESTful em Node.js com tipagem estrita em TypeScript e dashboard operacional em React com métricas de entregadores, entregas ativas e inspeção do barramento de eventos em tempo real.
